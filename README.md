# 健康トラッカー セットアップ手順

このフォルダには、あなた専用の健康管理アプリが入っています。
以下の手順通りに進めれば、Androidのホーム画面にアイコンが追加され、
普通のアプリのように使えるようになります。

## 事前に用意するもの
- Windows PC
- GitHubのアカウント(無料。持っていなければ手順1で作ります)
- Androidスマホ(Chromeブラウザ)

---

## 手順1: GitHubのアカウントを作る

1. https://github.com/ にアクセス
2. 右上の「Sign up」からメールアドレスなどを登録してアカウント作成

すでにアカウントがある場合はこの手順は飛ばしてください。

## 手順2: 新しいリポジトリ(置き場)を作る

1. GitHubにログインした状態で右上の「+」→「New repository」をクリック
2. Repository name に `health-tracker` などわかりやすい名前を入力
3. 「Public」を選択(Privateだと後で無料公開ができません)
4. 「Create repository」をクリック

## 手順3: ファイルをアップロードする

1. 作成したリポジトリのページで「Add file」→「Upload files」をクリック
2. このフォルダの中身(index.html, manifest.json, sw.js, icons フォルダ)を
   まとめてドラッグ&ドロップ
   - **フォルダ構造を保つのが重要です。** icons フォルダの中に
     icon-192.png と icon-512.png が入った状態でアップロードしてください
3. 下の「Commit changes」をクリックして保存

## 手順4: 無料公開(GitHub Pages)を有効にする

1. リポジトリ画面上部の「Settings」タブをクリック
2. 左メニューの「Pages」をクリック
3. 「Branch」を `main`、フォルダを `/ (root)` にして「Save」
4. 数分待つと、ページ上部に
   `https://あなたのアカウント名.github.io/health-tracker/` のようなURLが表示されます
   これがあなたのアプリのURLです

## 手順5: スマホのホーム画面に追加する

1. Androidスマホの **Chrome** で、手順4で表示されたURLを開く
   (例: `https://あなたのアカウント名.github.io/health-tracker/index.html`)
2. アプリが表示されることを確認
3. Chromeの右上「︙」メニュー →「ホーム画面に追加」をタップ
4. ホーム画面に「健康トラッカー」というアイコンが追加されます

これ以降は、そのアイコンをタップするだけで、普通のアプリのように起動します。

## データについて

- 入力したデータは **あなたのスマホの中(ブラウザの保存領域)** に保存されます。
  どこかのサーバーに送信されることはありません。
- そのため、**別の機種に機種変更したり、Chromeのデータを消去するとデータは消えます。**
- 定期的に、アプリ内の「CSVでバックアップを保存」ボタンを押して、
  ファイルとして保存しておくことをおすすめします(Googleドライブなどに置いておくと安心です)。
- **Firebase(Googleのクラウドサービス)と連携することもできます。** 連携すると、記録が
  クラウド上にも保存され、複数の端末から同じデータを見られるようになります。設定方法は
  `FIREBASE_SETUP.md` を参照してください。連携しなくても、今まで通りアプリ単体で問題なく使えます。

## 使い方の基本

- 炭水化物・お酒・運動: ボタンを押すたびに、その日の回数が1増えます
- 歩数・体重: 数字を入力して「保存」を押すと、その日の値として記録されます
  (同じ日にもう一度保存すると、後から入力した値で上書きされます)
- レポート欄では、直近14日/30日/90日の推移をグラフで確認できます

## 今後カスタマイズしたくなったら

`index.html` を メモ帳やVS Codeで開くと中身(見た目やボタンの文言など)を
編集できます。編集後、再度GitHubにアップロードし直せば反映されます。
